# arnon.net

The site, as one self-contained HTML file — no build step, no dependencies,
images inlined. Served by GitHub Pages.

It lives here because the Netlify account hosting it was suspended, taking the
site down with it. Static HTML is portable by nature, which is the reason this
took minutes rather than a rebuild.

To change the site: edit `index.html`, commit, push. Pages redeploys itself.
